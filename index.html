    How do I create the token? (Cómo crear el token)
    1. Open github.com/settings/personal-access-tokens/new (GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token).
    2. Token name: hotel-dialogue-audio. Expiration: 30 days is enough.
    3. Repository access: choose Only select repositories and pick just albertlemon1/Dialogs.
    4. Permissions → Repository permissions: set Contents to Read and write. Leave everything else as "No access".
    5. Click Generate token and copy it (it starts with github_pat_; it is shown only once).
    6. Paste it above. It is stored only in this browser (localStorage) and sent only to api.github.com. Delete the token on GitHub when you finish.

    Audio is committed to audio/<scenario>/b/<model>/<voice_id>/NN.mp3 (plus config.json with the chosen voices) on the branch above. If the branch doesn't exist on GitHub the commit will fail.
